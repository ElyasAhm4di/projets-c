# Projets C

Mes programmes en C, rangés au même endroit : exercices et TP d'un côté, projets plus longs de l'autre.

## Organisation

- `tp/` : exercices et travaux pratiques, un dossier par sujet.
- `projets/` : projets plus aboutis, un dossier par projet, chacun avec son propre README.

## Compiler

Chaque dossier se compile seul avec `gcc` :

```bash
gcc -Wall -Wextra -std=c11 -o programme main.c
./programme
```

Quand un projet grossit, il reçoit son `Makefile` dans son dossier.
